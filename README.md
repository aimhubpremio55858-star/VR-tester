# VR Box Hand Tracking - Versão Web 🌐

App de realidade virtual com rastreamento de mão para navegadores web em dispositivos Android.

## 🎯 Features

- ✅ **Hand Tracking** via MediaPipe
- ✅ **Detecção de Gestos** (Pinça, Punho, Palma aberta)
- ✅ **Realidade Mista** com câmera do dispositivo
- ✅ **Objetos 3D Interativos**
- ✅ **UI Responsiva** para mobile
- ✅ **Fullscreen Support**

## 📱 Compatibilidade

- **Android 5.0+** com navegador moderno
- **Chrome, Firefox, Edge**
- **Requer acesso à câmera**
